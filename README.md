# Python Image Filter Studio

Python Image Filter Studio is a simple Python program that allows users to apply different filters and effects to images.

## Features

- Convert images to grayscale
- Blur images
- Sharpen images
- Detect edges
- Increase image brightness
- Increase image contrast
- Create a black-and-white silhouette effect
- Save the edited image as a new file

## Technologies Used

- Python
- Pillow (PIL)

## How to Run

1. Install Pillow:

   pip install pillow

2. Run the program:

   py image_filter_studio.py

3. Enter the name or path of an image.

4. Choose a filter from the menu.

5. Enter a name for the edited image.

The program will save the new image in the project folder.
